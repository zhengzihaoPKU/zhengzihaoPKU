## 👋 关于我

我是**北京大学计算机学院博士研究生**，导师为**梅宏教授**和**陈翔教授**。

我的研究位于**物理智能（Physical Intelligence）**、**AI 系统（AI Systems）**和**系统设计自动化（System Design Automation）**的交叉方向。我尤其关注如何让具身智能与基础模型系统在真实计算平台上运行得**更快、更轻量、更易部署、更具自适应能力**。

博士阶段之前，我在北京大学获得硕士学位，主要研究**存内计算**与**计算机体系结构**。
